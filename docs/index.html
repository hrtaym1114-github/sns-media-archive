FEATURES

小さく使いやすく、必要な機能だけを丁寧に。

🎬

動画＋画像をまとめて

カルーセル投稿も含めて、対応SNSの全メディアを1クリックで一括取得。動画は再生互換性の高い H.264 で保存。

🔄

差分更新が自然

各アカウントに専用のアーカイブDBを持たせ、2回目以降は新着投稿だけを自動的に取得。重複ダウンロードは発生しません。

🖼

見たくなるギャラリー

サムネのホバーで拡大ポップ、左右矢印キーで前後切替、動画もブラウザ内で再生・ダウンロード可能。

🌐

6つのSNSを横断

プロフィールURLを貼り付ければSNSを自動判別。Instagram / X / TikTok / Pinterest / Tumblr / Bluesky に対応。

🛡

ローカル完結

あなたのMacの中だけで動きます。クラウドへのアップロード一切なし。Chromeのログイン済みCookieを直接利用。

🗑

削除も復元可能

「データ削除」を選んでも、メディアはアプリ内 trash/ へ退避するだけ。誤操作しても安心して戻せます。

WHY

「消える前に、ちゃんと残したい」
から始まった。

お気に入りのSNSアカウントの投稿は、いつまで見られるか分かりません。 アカウントの削除、凍結、プラットフォーム自体の変化 ― いつも誰かのサーバーに頼っている "ブックマーク" や "保存済み" は、思っているより脆いものです。

このツールは、そんな投稿たちを 手元のMacにまるごとアーカイブ するために作りました。 毎日少しずつ増えていく投稿は、ボタン1つで差分だけ取得。 いつでもオフラインで眺められる、自分だけのライブラリになります。

“ いいものをいつでも見返せる安心感を、手元に。 ”
QUICK START

3コマンドで動きます。

# 必要なツールをインストール（初回のみ） $ brew install gallery-dl ffmpeg # リポジトリを取得 $ git clone https://github.com/hrtaym1114-github/sns-media-archive $ cd sns-media-archive # 起動 → ブラウザが自動で開きます $ bash start.sh

動作要件

  • macOS（Linux/Windows は未検証）
  • Python 3.10+
  • gallery-dl、ffmpeg
  • 各SNSにログイン済みの Google Chrome

各SNSはログイン必須化が進んでいます。事前に Chrome で各サイトにログインしておくと、--cookies-from-browser 経由で認証を引き継げます。
